# กรอบเลือกแนบข้อความ — บันทึกการลงมือและตรวจสอบ

วันที่: 2026-10-03

สเปก: [tight-text-selection-design](../specs/2026-10-03-tight-text-selection-design.md)

## ผลที่ลงมือแล้ว

- แยกพื้นที่จัดบรรทัดที่บันทึกและส่งออกจากกรอบเลือกที่วัดด้วย TextMetrics ของข้อความที่วาดจริง รวมวรรณยุกต์ ขอบ เงา และขอบเผื่อ 3 พิกเซล
- พื้นที่คลิกและเส้นเลือกแนบข้อความ; พื้นที่ว่างของกรอบเดิมไม่บังข้อความข้างเคียง มีกรอบเดิมสำรองเมื่อข้อความว่างหรือไม่มี metrics ที่ใช้ได้
- Toolbar และมือจับตามมุมจริงเมื่อหมุนและซูม; ย้าย/หมุนใช้กรอบที่วัดไว้โดยไม่วาดหรือวัดข้อความซ้ำใน preview
- ลากข้างแสดงพื้นที่จัดบรรทัดชั่วคราวแล้วกลับเป็นกรอบแนบเมื่อปล่อยหรือยกเลิก ฟอนต์คงเดิม
- ลากมุมคงสัดส่วนและตรึงมุมตรงข้ามของกรอบเลือก หากการขยายจะพาพื้นที่จัดบรรทัดข้ามขอบภาพ ให้คงขนาดที่ยังอยู่ในภาพล่าสุด เพื่อให้เปิดใหม่และส่งออกเหมือนกัน
- คลิกเลือกโดยไม่ลากไม่วาดหรือบันทึก layout/style ใหม่ รวมงานเก่า

## หลักฐานการตรวจ

1. TDD ที่ overlay seam: ตรวจว่าเทสต์กรอบใหม่และจุดยึดมุมล้มก่อนแก้; ตรวจเพิ่มว่าการคลิกจน pointerup และมุมหมุนใกล้ขอบล้มก่อนแก้ จากนั้นไฟล์ `tests/cleaning/translationOverlay.test.ts` ผ่าน **90 เทสต์**
2. Chromium จริงผ่าน **16 กรณี** ด้วย `node scripts/verify-tight-selection.mjs`: zoom 100%/44%, sans-serif/serif ที่แสดงไทย, rotation 0/30/90/180 องศา โดย 180 องศาอยู่ใกล้ขอบล่าง ภาพจำลองมีไทยหลายบรรทัด วรรณยุกต์ ขอบ/เงา ข้อความข้างเคียง และข้อความว่าง
3. Browser ตรวจ alpha ของ glyph/effect อยู่ในกรอบ, `elementFromPoint` สำหรับข้อความ/มือจับ/ข้อความข้างเคียง, ตำแหน่งมือจับตามมุมที่หมุน, fixed corner, ยกเลิก/Undo/Redo, JSON บันทึกแล้วสร้าง overlay ใหม่, canvas และ JPEG ก่อน/หลังเลือก/เปิดใหม่, JPEG workspace/offscreen เท่ากัน และนับ measureText/fillText ระหว่าง preview ย้าย/หมุนว่าไม่เพิ่ม
4. `node node_modules/typescript/bin/tsc --noEmit`: ผ่าน exit 0
5. ESLint เฉพาะไฟล์โค้ดและทดสอบที่เปลี่ยน: ผ่าน exit 0
6. ชุดรวม `vitest run --root .`: 174 ไฟล์ผ่าน, 2 ไฟล์ล้ม, 1 ไฟล์ข้าม; **1,363 เทสต์ผ่าน, 2 ล้ม, 1 ข้าม**. เทสต์ VBScript Launcher ล้มใน sandbox และเทสต์การนำทาง MaskEditor ล้มในชุดรวม จากนั้นรันเฉพาะสองไฟล์ด้วยสิทธิ์ที่ให้ VBScript probe ทำงานได้ ผ่านทั้ง **42 เทสต์**. ไฟล์เหล่านี้ไม่มีการเปลี่ยนในงานนี้ ไม่อ้างว่าชุดรวมผ่านทุกเทสต์; ยังมีความไม่แน่นอนจากความล้มชั่วคราวของ MaskEditor ในชุดรวม
7. Code review จาก baseline `1d2291d2778b8cb4d36eea4be7e311549a4e1190`: Standards และ Spec ตรวจแยกกัน พบและแก้ click persistence, anchor/page-edge constraints และช่องว่าง browser validation; Spec ตรวจซ้ำแล้วไม่มีข้อบกพร่องที่ต้องแก้เพิ่ม
