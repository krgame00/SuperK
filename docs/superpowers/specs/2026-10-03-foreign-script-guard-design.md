# ตรวจภาษาปนในคำแปลไทย

ผู้ใช้อนุมัติแบบแก้ทั้งระบบแล้ว: ตรวจอักษรภาษาอื่นให้ครอบคลุม แปลซ้ำเมื่อพบ ตรวจคำแนะนำด้วยกฎเดียวกัน และแจ้งจุดที่ยังต้องแก้ รวมงานเก่า คงชื่อ/SFX ภาษาอังกฤษที่อนุญาต ไม่ลบตัวอักษรเพื่อซ่อนปัญหา

## หลักฐานและขอบเขต

ข้อความจริง `กลิ่นนี่มันมีมนמהขลังอะไรกันแน่...` มีอักษร Hebrew 2 ตัว แต่ countForeignScriptChars เดิมคืน 0 ขณะที่ kana ยังตรวจได้ 5 ตัว คำแปลปนอยู่ในข้อมูลจริง ไม่ใช่การวาดฟอนต์

## แบบที่อนุมัติ

- ใช้ตัวตรวจ Unicode ร่วมกัน รองรับ script นอก Thai/Latin รวม Hebrew/Arabic และ CJK นอก BMP อนุญาตตัวเลข punctuation สัญลักษณ์ และ combining accent ของ Thai/Latin
- กฎใช้เมื่อเป้าหมายเป็นภาษาไทยเท่านั้น ภาษาอื่นยังแปลเป็น script ของตนเองได้ ไม่ตรวจ original_text ที่ใช้เป็นหลักฐาน
- ใช้การแปลซ้ำจากภาพต้นฉบับเดิมที่มีอยู่ จำกัดหนึ่งครั้งและเก็บผลที่สะอาดกว่า ไม่เพิ่ม retry ไม่จำกัด
- หากยังปน ให้ review เป็น needs_review พร้อมตัวอักษรที่พบ แม้ provider ตรวจไม่ได้หรืออ้างว่าผ่าน คำแนะนำที่ยังปนไม่เป็น suggested และไม่เปิดปุ่มใช้
- ใช้ guard ตอนรับคำแนะนำจาก API/บน client และตอนเปิด editor ของงานเก่า โดยคงข้อความและ geometry เดิม
- แสกนงานเก่าและรายงานส่งออกใช้ตัวตรวจเดียวกัน ระบบไม่แก้ข้อความที่บันทึกเงียบ ๆ
- เพิ่มข้อความเตือนจำนวนจุดและจุดที่ยังปนหลังแปล รวมคำแปลที่กู้คืนภายหลัง ไม่แสดงเพียงผ่านโดยไม่แจ้ง

## การตรวจรับ

เทสต์ตัวอย่างจริง Hebrew, Arabic, Greek, Myanmar, CJK supplementary, halfwidth kana; Thai/Latin/emoji/ตัวเลขไม่เตือนผิด; Thai-only scope; retry/keep-cleaner/dirty-final warning; review false approval/bad suggestion/network failure; งานเก่า editor รับคำแนะนำปนไม่ได้; TSC/lint/review และ production build ก่อนเปิดใช้

การอัปเดตบริการต้องใช้คำยืนยันบันทึกงานปัจจุบัน ไม่มี provider calls กับงานจริงระหว่างทดสอบ
