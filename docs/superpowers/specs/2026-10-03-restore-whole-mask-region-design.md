# กู้ภาพเดิมทั้งจุด — 2026-10-03

## พฤติกรรมที่เลือก

ผู้ใช้เลือกแบบเลือกกรอบแล้วกู้ภาพเดิมทั้งจุด แทนการคลิกกู้เฉพาะก้อน mask ที่เชื่อมกัน

- เลือกกรอบ เช่น #5 แล้วกดปุ่มใหม่ **กู้ภาพเดิมทั้งจุด** ที่แถบเครื่องมือหลัก
- คืนพิกเซลต้นฉบับทั้งหมดภายในกรอบที่เลือก รวมจุดที่เคยคลีนหรือแก้ mask ไม่ต้องระบายแปรงและไม่ต้องกดใช้กับจุดนี้ซ้ำ
- คงกรอบที่เลือกไว้และแสดงภาพที่คลีนแล้วหลังสำเร็จ เพื่อให้เห็นผลการกู้จริง
- เครื่องมือกู้ภาพเดิมด้วยแปรงยังใช้กู้เฉพาะส่วนได้ และใช้ชื่อ **กู้เฉพาะส่วน** ให้แยกจากปุ่มกู้ทั้งจุด
- การเลือกกรอบอย่างเดียวไม่เปลี่ยนภาพ ต้องกดปุ่มกู้ทั้งจุด

## การทำงาน

ใช้เส้นทาง `onRetry(regionId, mask, cleaner, "protect")` ที่มีอยู่ใน MaskEditor สร้าง mask สีขาวเต็มกรอบที่เลือกและสีดำภายนอกกรอบ ส่งทันทีโดยไม่ใช้สีแดงหรือรอยแปรงปัจจุบันเป็นเงื่อนไข จึงทำงานได้แม้ mask แสดงผลว่างอยู่

Backend คัดลอกพิกเซลจาก source_image กลับลง clean_image เฉพาะ mask ที่อนุญาต ล้าง applied/review mask ตรงนั้น และบันทึกการปกป้องบริเวณดังกล่าว ไม่ต้องเพิ่มอัลกอริทึมหรือ API ใหม่

หลังสำเร็จ ล้าง draft และประวัติแก้ mask ของจุดที่กู้เพื่อไม่ให้รอยเก่ากลับมาเมื่อเปิดใหม่ ผลภาพและ mask ใช้ผลตอบกลับจริงของระบบ การกู้ทั้งจุดไม่เพิ่มการย้อนภาพที่บันทึกแล้วลงใน Undo ของแปรง

## ขอบเขตและข้อผิดพลาด

- จำกัดภายในกรอบที่เลือก พื้นที่นอกกรอบต้องเหมือนก่อนกู้ หากกรอบซ้อนกัน ส่วนที่ซ้อนภายในกรอบที่เลือกจะคืนต้นฉบับด้วย
- ปิดปุ่มเมื่อยังไม่มีข้อมูลภาพ/กรอบ หรือกำลังส่งคำขอ ป้องกันการกดซ้ำและเปลี่ยนกรอบระหว่างกู้
- หากส่งหรือบันทึกไม่สำเร็จ แสดงข้อผิดพลาด เก็บ draft และตัวเลือกปัจจุบันไว้ให้ลองใหม่
- การจับคู่กรอบของงานเก่าใช้เส้นทาง recovery ที่มีอยู่ ต้องจำกัด mask ตามกรอบที่ backend ยอมรับและแจ้งเมื่อจับคู่เปลี่ยน
- ไม่เปลี่ยนข้อความแปลหรือการเลือกแหล่งส่งออกของหน้า ปุ่มนี้กู้ภาพต้นฉบับในผลคลีน

## เกณฑ์ตรวจรับ

1. เลือก #5 แล้วกดกู้ครั้งเดียวโดยไม่มี pointer stroke ส่ง protect ด้วย mask เต็มกรอบ
2. ไม่มีพิกเซลที่เลือกภายนอกกรอบ รวมกรอบใกล้ขอบภาพ
3. กู้ได้ทั้ง applied mask ที่มีสีแดงและ mask ที่ว่าง ไม่มีเงื่อนไขให้วาดก่อน
4. สำเร็จแล้วเห็นภาพจริงที่กู้ รอย draft เก่าไม่กลับมาเมื่อสลับกรอบหรือเปิดใหม่
5. ล้มเหลวแล้วไม่รายงานสำเร็จ ไม่ล้าง draft และกดลองใหม่ได้
6. เครื่องมือแปรงกู้เฉพาะส่วนและการคลีนจุดอื่นยังทำงานตามเดิม

## สถานะ

ผู้ใช้อนุมัติเอกสารและให้ทำต่อแล้ว ลงมือและอัปเดตเว็บเรียบร้อย ดูผลตรวจและ runtime ล่าสุดใน `docs/superpowers/plans/2026-10-03-restore-whole-mask-region.md`
