# กรอบเลือกพอดีข้อความ — 2026-10-03

## แบบที่ผู้ใช้เลือก

กรอบเลือกแนบข้อความที่วาดจริงอัตโนมัติ เผื่อขอบและเงาเล็กน้อย คงขนาดตัวอักษร ตำแหน่ง และการแบ่งบรรทัดเดิม ไม่ต้องกดปุ่มปรับกรอบ

## สาเหตุเชิงโครงสร้างที่ตรวจพบ

`translationOverlay.ts` ใช้ `currentBw/currentBh` เป็นทั้งพื้นที่จัดบรรทัด ขนาด canvas และขนาด wrapper ที่แสดงเส้นเลือก/วางมือจับ ข้อความถูกวาดกึ่งกลาง canvas จึงมีพื้นที่ว่างรอบข้อความได้ โดยเฉพาะพื้นที่ต้นฉบับที่สูงหรือกว้างกว่าคำแปล หลักฐานนี้อธิบายพฤติกรรมของโค้ด แต่ยังไม่ได้ยืนยันค่ากรอบจริงจากภาพของผู้ใช้

## การทำงานที่เสนอ

- เก็บพื้นที่จัดบรรทัดเดิมไว้เพื่อรักษาข้อความและข้อมูลที่บันทึก/ส่งออก
- คำนวณขอบเขตข้อความจากบรรทัดที่วาดจริงและ TextMetrics ของฟอนต์จริง รวมวรรณยุกต์ ขอบตัวอักษร และเงา ใช้ค่าขนาดตัวอักษรสำรองเมื่อเบราว์เซอร์ไม่มี bounding metrics
- เพิ่มขอบเผื่อประมาณ 3 พิกเซลในภาพต้นฉบับ จำกัดขอบเขตไม่ให้เกิน canvas ที่วาดจริง
- แสดงเส้นเลือกและเส้น hover รอบขอบเขตดังกล่าว วาง toolbar และมือจับรอบกรอบเลือกใหม่นี้
- คงจุดหมุนของพื้นที่จัดบรรทัดเดิม คำนวณตำแหน่งกรอบ/มือจับที่หมุนแล้วจากพิกัดจริง ไม่ใช้กรอบ axis-aligned ของข้อความที่หมุนแทน
- ลากย้าย/หมุนยังใช้ geometry เดิม มือจับมุมขยายสัดส่วนทั้งกรอบและฟอนต์; มือจับข้างยังเปลี่ยนความกว้างและจัดบรรทัดโดยคงฟอนต์ ใช้ระยะเปลี่ยนจากจุดเริ่มลากเพื่อป้องกันกรอบเด้งจาก offset ใหม่
- วัดขอบเขตใหม่เฉพาะเมื่อวาดข้อความใหม่ การลากย้าย/หมุนใช้ค่าที่วัดไว้ เพื่อรักษาการลากลื่น
- หากข้อความว่างหรือวัดไม่ได้ ใช้กรอบเดิมเป็น fallback เพื่อให้ยังเลือกและแก้ไขได้

## ขอบเขต

เปลี่ยนเส้นกรอบและตำแหน่งเครื่องมือสำหรับข้อความแปล ไม่เปลี่ยนกรอบ mask, OCR, ฟอนต์ หรือผลส่งออก เพียงเลือกข้อความต้องไม่เขียน layoutAdjustment ใหม่ งานเก่าไม่ต้องย้ายข้อมูล

## เกณฑ์ตรวจรับ

1. ข้อความแคบในพื้นที่สูง/กว้างมีกรอบเลือกแนบตัวข้อความโดยไม่ตัดวรรณยุกต์ ขอบ และเงา
2. ก่อนและหลังเลือก ข้อความวาดด้วยบรรทัด ขนาดฟอนต์ และตำแหน่งเดิม ผลส่งออกเดิม
3. Toolbar และมือจับอิงกรอบใหม่ทั้งที่ซูมต่ำและเมื่อหมุน
4. ลากย้าย/หมุนไม่วัดข้อความใหม่ทุก pointer event มือจับมุมคงสัดส่วน มือจับข้างคงฟอนต์ และไม่มีการกระโดดเมื่อเริ่มลาก
5. Undo/Redo และการเปิดงานเก่ายังใช้ geometry ที่บันทึกเดิม

## สถานะ

ผู้ใช้เลือกแบบอัตโนมัติแล้ว เอกสารผ่านการตรวจขอบเขตและความสอดคล้อง รอการตรวจเอกสารก่อนเขียนแผนตาม skill brainstorming
