# SuperK - Manga Translator

## วิธีเปิด

```bash
npm run dev
```

เปิด http://localhost:3000

## Stack
- Next.js + Gemini Vision API (OCR + แปล)
- Inpainting ลบข้อความต้นฉบับ
- Text overlay ทับลงบนภาพ

## Features
- แปล manga ทุกภาษา
- 18+ Mode (หั่นภาพ bypass content filter)
- Source language selector
- Text style customization (font, color, outline, size)
- Undo/Redo + Keyboard shortcuts
- Download PNG/ZIP/CBZ/PDF
- Drag & drop reorder pages
